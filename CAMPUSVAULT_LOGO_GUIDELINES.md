# CampusVault Official Logo & Brand Identity Guidelines

> **IMPORTANT**: This is the official, definitive logo and brand identity for **CampusVault**. This exact visual design, icon, color palette, wordmark, and tagline must be used for ALL logo, banner, marketing, UI, and branding requests. No alternative logo design should ever be used.

---

## 🎨 1. Logo Visual Breakdown

```
    ┌──────────────┐
    │    \   /     │  <-- Stylized glowing violet "V" emblem
    │     \ /      │      in a dark rounded app tile
    └──────────────┘
      CampusVault     <-- "Campus" (White) + "Vault" (Vibrant Purple)
 Learn · Earn · Collaborate <-- Official Tagline
```

---

## 💎 2. Core Components

### A. App Icon / Symbol
- **Shape**: Dark rounded rectangle (squircle / app-icon container).
- **Emblem**: Stylized **"V"** composed of two sleek diagonal beams angled downward toward a center node.
- **Color & Effect**: Radiant violet-purple gradient with subtle outer glow on a dark background.

### B. Wordmark
- **Text**: `CampusVault` (Single word, camel case).
- **"Campus"**: Bold, clean white sans-serif (`#FFFFFF`).
- **"Vault"**: Bold, vibrant electric purple / violet sans-serif (`#9353D3` / `#8B5CF6`).

### C. Tagline
- **Text**: `Learn · Earn · Collaborate`
- **Style**: Lightweight sans-serif, letter-spaced, muted off-white/light gray (`#A1A1AA`).
- **Position**: Centered directly below `CampusVault`.

## 📌 4. Usage Rules & Constraints

1. **Always Use "CampusVault" Wordmark**: The word "Campus" is White, and "Vault" is Purple.
2. **Always Include the Stylized "V" Icon**: The emblem must be the dual-beam glowing violet "V".
3. **Official Tagline**: `Learn · Earn · Collaborate` separated by mid-dots (`·`).
4. **Strict Consistency**: NEVER substitute another logo style, icon, or color scheme when generating images, UI headers, splash screens, banners, or documents for CampusVault.
